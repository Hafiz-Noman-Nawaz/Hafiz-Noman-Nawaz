- High-frequency streaming UI tuned for smooth ~60 FPS interaction

`React` `Zustand` `SSE`

**Genius Fixers**
Operations dashboard for managing service business workflows.

- Built with React / Next.js
- Reusable component architecture
- Searchable, paginated data tables
- Modal-driven forms with client-side validation
- REST API integration for clients, service bookings, and financial records

`React` `Next.js` `REST APIs`
